L1 to L2 In Resort (OTS) Task Types

Procedures for Travelers at the property or Enroute.

GOLDEN RULE: If booking is Same Day Arrival or OTS and provider will not accept booking -> PASS TO L2 IN RESORT IMMEDIATELY.

Hotel Cannot Locate Booking

L1 Action: Call provider (including 3rd parties) to reconfirm.
Actions: Resend LPO, Resend/Clarify VCC or Payment methods.
OTS Timeout: If unable to contact hotel within 20 minutes -> Transfer to L2 In Resort.
(If NOT OTS, continue attempting until success, rejection, or client arrival).

Warm Transfer Process (Phone)

Inform customer about transfer to specialized team and wait for L2 to pick up.

Required Details for L2:

  • Client Info: Booking ref, Agency name, TA name, Callback number.
  • Case Info: Original task type vs what it turned into (e.g., Reconfirmation -> Relocation).
  • Remarks: Pregnant mom, family traveling together, wheelchair access, beach preference.
Email Tasks: Transfer ticket to In Resort FD Group.

Nationality & Mapping Issues (OTS)

Nationality Scenario 1 (Proof Exists):

  • Customer Error: Check extra cost -> Inform Agency -> Decision (Accept/Cancel).
  • WB Error: (System/CS error) -> Pass to L2 In Resort.
Exceptions (German/Expedia/LoveHolidays): We state EU residence. If rejected or extra cost -> Pass to L2 In Resort FD Group.

Mapping Errors:

  • WB Error: Escalate to L2.
  • Client Error: Offer FOC cancellation or Rebook at correct hotel (client pays difference).

Hotel Changes & Groups

Name Change: L1 reconfirms amenities/rating. If client refuses to check-in -> Pass to L2.

Group Reject: L1 validates if same customer. If hotel still rejects legitimate FIT -> Pass to L2 In Resort FD Group.

Note: CTRIP remains with L1 until completion.

Transfers (Vehicle/Driver)

  • L1 Handles: Cancellations, Amendments, Creations, Special requests.
  • L2 Handles: OTS Quality issues (Vehicle not standard) or Driver No-Show.
If No-Show, L1 should try calling supplier first. Most cases end as L2 CE Complaint.
