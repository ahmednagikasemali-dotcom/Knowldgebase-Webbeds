Fraud Handling Guidelines

  • All fraud scenarios must be escalated immediately.
  • Preventive measures must be applied before confirmation.
  • Special Investigations handles all high-risk scenarios.
  • Always document actions and client communication.

Ghost Booking – Client Cannot See Booking

  1. Verify booking in system logs.
  2. Confirm client cannot view booking.
  3. Escalate to Fraud Detection team.
  4. Cancel booking & delete any VCC.

Ghost Booking – Not Visible on Both Sides

  1. Validate booking reference and system logs.
  2. Escalate case to Special Investigations.
  3. Confirm no financial impact.

System Hacking / Security Breach

  1. High priority case – escalate immediately.
  2. Cancel affected bookings.
  3. Delete all related VCCs.
  4. Document actions in system.
Do not confirm breach externally until investigation completes.

Unauthorized / Compromised Credit Card

  1. Verify cardholder dispute details.
  2. Cancel booking immediately.
  3. Delete any VCC issued.
  4. Escalate to Alert & Investigations Team.
