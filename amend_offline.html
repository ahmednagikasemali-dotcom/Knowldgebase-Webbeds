How to Amend Offline Booking

Overview

This SOP explains how to perform an offline booking amendment using the Amend Offline functionality in DOTWConnect.

Offline amendments require prior coordination with the hotel/supplier and approval of additional selling price if applicable.
  • Ensure booking has been amended first with hotel/supplier.
  • Ensure customer has accepted any additional selling price.
  • Amend Offline button becomes available at the bottom of booking summary.
  • Amend invoiced or cancelled bookings.
  • Adjust cost and selling price (whole stay or per night).
  • Reflect compensation amounts.
  • Adjust mark-up % including negative up to -99%.
  • Adjust miscellaneous bookings cost/price & mark-up.
  • Name, Travel Dates, Occupancy, Meal Plan, Bedding, Room Type.
  • Cost Price (Total & Nightly), Selling Price (Total & Nightly).
  • Mark-up %, Compensation Amounts, Cancellation Policy.
  • Enter whole stay cost/selling price → apply → system divides per night.
  • Adjust per night cost → calculate selling price automatically.
  • Adjust mark-up % if authorized → calculate selling price.
  • Manually adjust selling price & mark-up if needed.
  • Adjust booking cost only (whole stay or per night) if required.
  • Date changes update Price Variation Table → enter new cost → calculate selling price.
  • Enter approved compensation in “Customer Compensation Amount” box.
  • Adjust mark-up % if applicable.
  • Apply also for invoiced bookings or cancelled bookings.
  • Click "+ Cancellation Policy" link to adjust deadline if needed.
  • Choose whether to send LPO/Booking Confirmation to Supplier/Customer.
  • Default is YES for both; can override if rate change is internal.
  • Tick box confirming amendment is coordinated with supplier.
  • Click "SAVE OFFLINE" to complete process.
  • VCC & invoices update automatically if applicable.
  • Pre-travel, 1+ day before check-in → no need to notify finance.
  • Pre-travel, same day → notify VCC team for increases.
  • Past check-in/invoiced → notify VCC team if rates increased.
