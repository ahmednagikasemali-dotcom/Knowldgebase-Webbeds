Miscellaneous Booking (DOTWConnect)

Purpose

This SOP explains how to create a Miscellaneous Booking (MISC) in DOTWConnect when a booking cannot be created or amended online.

  • Go to Operations
  • Click MISC
  • Select BOOKINGS
  • Enter client name in Company Name
  • Select correct customer profile
  • Enter number of units
  • Click Filter Customers
  • Select requested user account if specified
  • If not specified, select Main User
  • Service Name (reason + DOTW reference)
  • Country & City
  • Booking description (max 255 characters)
  • Total number of occupants
  • Main guest name
  • Travel dates
  • Preferred time (N/A if not applicable)
  • Internal reference (consultant name)
  • Click Save
  • Open the generated Miscellaneous Number
  • Attach supplier
  • Payable currency auto-populates
Supplier currency cannot be changed.
  • Enter booking cost (daily or total)
  • System auto-calculates selling price
  • Use Mark-up Calculator if adjustment is needed
  • Set cancellation deadline
  • Penalty must be 100%
  • Enter supplier reference or “Confirmed”
  • Set customer & supplier email options
  • Customer acceptance usually set to No
  • Click Confirm Misc
Always review summary before final confirmation.

Ensure the following options are selected Yes to allow the customer to pay with a credit card:

Setting Description Yes No
Customer Acceptance Needed Must be YES to allow credit card payment for MISC.
Send email communication to customer Must be YES to send notification emails to customers.
Send email communication to supplier Optional.
Payable by Customer? Must be YES for customer to pay MISC.
⚠️ Warning: If you select No for "Customer Acceptance Needed" or "Send email communication to customer," the customer will NOT be able to pay with a credit card, and the created MISC will not be payable.
