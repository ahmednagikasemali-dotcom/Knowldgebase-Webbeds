1. Homepage & Menu Options

The Maker homepage is the first screen after logging in. It features a top menu and search options for hotels within the platform.

Menu Options Description:

  • Hotel Dir: Search for hotels WebBeds currently has contracts with.
  • Bookings: Search for existing bookings or transfers (SH/ST numbers).
  • Agent: Search for travel agencies and find client account settings.
  • Destinations: Look up hotels by selecting a specific city or area first.
  • Admin: Check valid guest nationalities for specific contracts.

2. Hotel Dir. (Directory)

Use the Hotel Name field in the search form to locate a property. Results display the full hotel name and location.

Key Buttons:

  • [Add/Edit rooms]: Shows channels available for booking rooms.
  • [Edit]: View the full profile (Address, Sunhotel Class/Rating, Phone, and the Contractor manager).

Channel Color Coding:

  • Orange: Non-XML rooms (Direct Contract or DMC).
  • Green: 3rd Party / XML rooms.
  • Red: Not Active rooms.
Each supplier has a unique ID to identify the specific room provider in Maker.

3. Agent (Travel Agencies)

Search by agency name. Important: Some agencies have multiple accounts with different settings.

Tab Details:

  • Agent Details: Physical address, Sales Manager (Sales Responsible), and Market Settings (defines the handling CS office: Europe, MEA, APAC).
  • Rates/Account: Default payment currency and commission settings.
  • Options: Payment method (Invoice vs Credit Card). If the Invoice box is ticked, the method is via Invoice.

4. Destinations & Transfers

Search hotels or transfers based on geographical hierarchy (Country > City).

Transfer Providers:

Clicking this button next to a city shows a list of suppliers, their contact details, and the payment currency. If blank, no transfers are offered in that city.

5. Advanced Booking Search

Crucial: You must select the correct Operations Brand (e.g., WebBeds Europe). If the brand is incorrect, the system will not find the SH/ST number.

Search Methods:

  • Reference Number: SH######## for Bookings, ST######## for Transfers. Search multiple by using a comma (,).
  • Agent Reference: Client’s internal number (takes longer to search).
  • Guest Name & Date: Lead name + Check-in date.

6. Booking Details Deep-Dive

A. Main Info:

  • Room ID: Used to track the specific provider room code.
  • Arrival/Departure: Check-in and out dates.
  • Room Type Blue Text: Indicates the booking channel.

B. Payment & History:

  • XMLTotalPrice: The buying price (Net) we pay to the provider.
  • XMLID: Supplier reference or Hotel Confirmation Number (HCN).
  • CR (Cancellation Rules): Click to see deadlines and penalties.
  • View Booking History: Check Room History for XML provider and Customer History for guest nationality.

7. Booking Actions List

  • [Voucher]: Edit guest names. Use Save Voucher and then Send.
  • [Create Manual Voucher]: Allows manual changes to dates/details on the printed voucher only (does not update the system DB).
  • [Resend Reservation Email]: Resends LPO to hotel/DMC. Recipient email can be edited here.
  • [Note]: View/Add internal notes. All price/manual changes are logged under the user ID.
  • [Cancel/Delete]: Cancel is for XML. Delete is for manual status change (must contact hotel first).

8. BackOffice Operations

Used for manual adjustments after the booking is confirmed.

  • Price Changes: Adjusting Net or Selling prices.
  • Change Payment Method: Switching between Invoice and Credit Card (VCC).
  • Provider Swap: Adjusting the room provider/source in special cases.

9. Hotel Maker (VCC & Stop Sales)

Virtual Credit Card (VCC):

  • Access the payment tab to find card details.
  • Check "Can be charged" to see if charging is allowed at Check-in or Check-out.

Contract Management:

  • Stop Sales: Check if a contract has stop-sales applied for specific dates.
  • Hotel Info: View main reservations email and finance contacts.

10. Admin & Nationality Checks

Ensuring guest nationality compliance for specific contracts.

  1. Select Admin > Edit Providers.
  2. Search for the contract name (Ctrl+F).
  3. Check if the specific market/country is Open or Closed.
Note: Countries like Belarus might be grouped under CIS (Commonwealth of Independent States).
