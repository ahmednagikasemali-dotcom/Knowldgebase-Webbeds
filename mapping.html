Mapping Error – WebBeds

Step 1: Identify Type of Mapping Error

Select the type of mapping error:

Check that hotel/room ID in our system matches client’s booking.

Request XML logs and hotel ID as proof.

Open ticket: WebBeds Connectivity → Platform & Partner Support → Client Connectivity / XML → Book Failure / Mapping Discrepancies.

Optionally notify mapping team or TL for assistance.

Provide client with correct hotel or suitable alternative:

  • Same area/resort with same reviews → offer directly.
  • Same area/resort but downgrade → discounted rate if WebBeds error.
  • Different area/country → cancel wrong booking FOC, offer alternative.

Update DOTW, Backoffice, MISC and document all communications.

Potential Loss = Original Booking Cost + (Alternative Cost – Original Selling Cost)
Actual Loss = Total Paid – Original Selling Price
