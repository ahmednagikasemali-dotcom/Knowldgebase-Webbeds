Offline Technique & Forms

  1. If it’s transfer request: we should have the full flight details and the destinations.
  2. Accommodation request: must have full data like dates, how many pax, type of rooms, nationality & area if possible.
  3. If there are children, ask the client to advise their age.

To be able to make follow up or searching for the request easier.
