L1 to L2 PST Task Types

Liability determination, Triaging process, and Escalation protocols.

General Responsibility

L1: Determines liability based on triaging.
L2: Handles only if WebBeds (WB) is liable and there is a potential financial loss.

Nationality Issues

Scenario 1: Incorrect Nationality Proof Exists

Establish source: Customer vs WB responsibility.

Customer Responsibility: (Selected wrong channel).
- Check if provider accepts with extra cost.
- Send proof to agency and request decision (Accept price or Cancel).
WB Responsibility: (System issue or CS error).
- If provider accommodates for free: Confirm.
- If NOT free or rejected: Pass to L2 (PST - Hotel/Suppliers)

Scenario 2: Assumption of Nationality (Validation Request)

Respond to provider to keep booking valid. Request documentation (Passport) from agency.

EXCEPTION: German Market / Expedia / LoveHolidays
Inform provider: Customer has EU residence and is protected. We do not validate.
If rejected/extra cost: Pass to L2 (FD group PST - Hotel/Suppliers)

Mapping Error

L1 investigates the source of the error.

  • If WB Issue: Escalate to L2
  • If Client Error: Offer FOC cancellation (if hotel agrees) or Rebooking (client pays difference).

Note: Always involve the Sales Manager.

Handling Rate Differences

  • If client disputes rate: Forward to Disputes Team.
  • Special Case (IT Claim): If client claims different rate after confirmation, involve IT Team.
  • While waiting: If Sales Manager accepts, charge difference to Sales. If not, wait for IT findings.

Renovations & Group Bookings

Renovations

L1 handles alerts. If relocation is needed: Pass to L2

Group Bookings (9+ Passengers)

If same customer: Inform them to contact groups@webbeds.com.
If different customers: Inform property it is FIT.
If hotel rejects but FIT policy was respected: L2 will handle

Hotelmize & Blacklisted Clients

Hotelmize: L1 tries to persuade provider or reinstate original. If impossible: Transfer to L2

Blacklisted: L1 asks client to cancel. If commercial team requests relocation: Transfer to L2

Visa & General Client Errors

Visa Bookings: L1 requests flight details for validation. If still rejected: Pass to L2

Client Errors (Adult only, Pets, names): L1 explains error and requests cancellation. If relocation is forced by commercial: Pass to L2

Exception: For CTRIP, all tasks remain with L1 with specific L2 involvement.
