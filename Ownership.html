Agent KPI – Ownership Steps

📥

Step 1: Ticket Received

  • Follow up the call
  • Reopen ticket
  • Duplicate ticket
  • Waiver request
📌 Example: Customer calls about a ticket that already exists.
📂

Step 2: Verify Original Ticket

✅ Original ticket is open
  • Do not change ownership
  • Mark new ticket as duplicate
❌ Original ticket closed or missing follow-up
  • Agent must follow up properly
📌 Example: Ticket #100 is open → Ticket #101 marked as Duplicate.
🧠

Step 3: Can the agent resolve it?

✅ Yes – resolved
  • Ownership moves to second agent if needed
  • Follow all linked tickets
❌ No – unresolved
  • Leave clear notes
  • Original owner responsible
📌 Example: Agent contacted the hotel and resolved the issue successfully.
🔄

Step 4: Reopen Ticket

  • Reopening does not change ownership
  • Original owner is responsible
📌 Example: Customer replied after closure → same owner continues.
📞

Step 5: Waiver Request

⚠️ External contact required
  • Contact hotel / supplier
  • Record response clearly
📌 Example: Free cancellation request after the deadline.
📊

Step 6: Impact on KPI Ownership

  • Ownership KPI counts only if agent resolved ticket
  • Clear documentation required
  • Do not count for original owner shifts
