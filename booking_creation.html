Accommodation Booking (DOTWConnect)

📄
❓
Case Category: Booking Creation
Type: Booking Creation

Purpose

This page is a training and reference guide to help employees create Accommodation Bookings correctly in DOTWConnect.

  • Go to Operations
  • Click NEW BOOKING
  • Select ACCOMMODATION BOOKING
This opens the accommodation booking workflow.
  • Enter client name in COMPANY NAME
  • Select the correct profile from the list
  • Click FILTER CUSTOMERS
Clients usually have multiple user profiles under the same account.
  • If client specifies an account → select it
  • If not specified → choose MAIN USER
  • Search by city, hotel, location, or landmark
  • Select from system recommendations if needed
DOTWConnect may suggest similar cities, hotels, or landmarks.
  • Enter Check-in & Check-out dates
  • Or adjust Number of Nights
  • Default is double occupancy
  • Adjust adults & children
  • Enter exact children ages
Rates are calculated automatically based on children age & hotel contract.
  • Default: Best Available
  • Change according to client request
  • Select accurate nationality
  • Select country of residence
Incorrect nationality or residence may result in wrong pricing.
  • Click Add Room
  • Same hotel & same dates only
Different hotels or dates require separate bookings.
  • Click SEE ROOM TYPES
  • Check total selling price
  • Review cancellation policy
Never quote the lowest nightly price to clients.
  • Enter guest names (English only)
  • No special characters or spaces
  • Click BOOK ROOMS
  • ON REQUEST rooms are not guaranteed
  • Currency cannot be changed after booking
  • Special requests are subject to availability
