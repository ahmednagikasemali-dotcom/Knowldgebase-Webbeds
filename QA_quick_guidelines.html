QA Rules – Agent Actions

📞

Step 1: Take Action on Any Call

An action must be taken anyway to make the call time worth it.

📌 Example: If a client calls for any request, the agent should either send an email (if not urgent) or call the provider (if urgent).
⚡

Step 2: Calls Take Priority Over Tickets

The call has priority over the ticket, even if the ticket owner is available.

📌 Example: Client calls regarding a new ticket → the agent focuses on the call first.
✉️

Step 3: Client Requests

  • If request is urgent or pending → call hotel/provider and keep ticket under owner’s name
  • If not urgent → send email to hotel/provider, keep ticket under owner’s name
  • Reply to client with provided info and add clear notes on ticket
📌 Example: Client calls for tomorrow's arrival → email + phone call to hotel to resolve ASAP.
🏨

Step 4: FOC Approval Checks

  • If client says hotel approved FOC and it's DC/CM/Dynamic → agent contacts hotel to confirm, even if assigned to another agent
  • If it's TP booking → agent sends email to TP to confirm, inform client about response delay
📌 Example: Client mentions hotel approved FOC → agent calls hotel to confirm before updating ticket.
⏳

Step 5: Pending Requests >5 Days

Any request pending for over 5 days, even if not urgent → agent should call hotel/provider or send follow-up email.

📌 Example: Ticket pending 6 days → agent calls hotel to push for updates, then emails client.
📋

Step 6: Cannot Reach Hotel/Provider

Even if the hotel/provider is unreachable, take action by email and keep client informed.

📌 Example: No answer from hotel → send email chasing update, notify client about follow-up.
