HCN – Reconfirmation Process

Overview

This SOP explains how to handle HCN (Hotel Confirmation Number) requests, reconfirm bookings, and communicate correctly with clients and suppliers.

  • All bookings are confirmed by default except On-Request or errored bookings.
  • Confirmed does not mean fully secured.
  • The technical term is Reconfirmation.
  • Reconfirmation means validating all booking details and obtaining:
    • Hotel Confirmation Number (HCN)
    • Hotelier’s name
Proper reconfirmation reduces Operations workload by more than 50%.
  • Open the booking on its platform.
  • Verify if the booking is already confirmed.
  • If confirmed → capture the HCN.
  • Capture hotelier’s name if available.
  • If booking is not confirmed → run Dexter.
  • Check provider’s platform if access is available.
  • Otherwise, contact the provider via official email.
  • Update booking with HCN & hotelier’s name.
  • Inform the client clearly.
