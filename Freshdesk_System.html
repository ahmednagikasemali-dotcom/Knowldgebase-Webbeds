FRESHDESK’S BENEFITS

Freshdesk is a special cloud-based CRM tool designed to improve customer support via an advanced ticketing system.

  • Streamlined workflow: Emails and notes in a singular ticket trail.
  • Personalized Distribution: Efficient task sharing among team members.
  • Tracking: Assess team workload and reduce repetition.
  • Knowledge base: Built-in database for quick answers.

ACTIVATING & LOGGING IN

Initial activation via email from Freshworks.

WebBeds SSO (Single Sign-On): Users login via WebBeds SSO, providing secure access to multiple applications with one set of credentials.

HOMEPAGE ACCESS COMPONENTS

The interface consists of the following key areas:

  • Section Icons: Left-side navigation.
  • Main Working Page: Central workspace.
  • New Email/Ticket: Outbound trail creation.
  • Search Box: Global search engine.
  • Status Toggle: Manage auto-assignment availability.

DASHBOARD FILTERS & METRICS

Dashboards provide performance summaries.

Group Filters

Used by Supervisors to isolate data for specific groups (e.g., Mandarin group). Only Admins can create these groups.

SEARCH ENGINE FUNCTIONALITY

The search bar supports:

  • References: Booking Ref #, Ticket ID.
  • Keywords: Hotel Name, Supplier Name.
  • Knowledge Base: Direct search for solution articles.
  • Characters: Supports Pinyin and other foreign characters.

USER PROFILE & SIGNATURE

To set your signature: Navigate to User Menu > Profile Settings. Input your WebBeds approved signature in the designated box. Click Save Change to ensure it appears in outbound emails.

SUMMARY PAGE COMPONENTS

Features include: Sorting (Date/Status), Layout toggles (Card/Table), Export options (CSV/Excel for Supervisors), and Ticket Filtering on the right panel.

ASSIGNMENT LOGIC & SCENARIOS

Manual Move (Execute Scenarios)

Mis-routed tickets: Click Ellipsis (...) > Execute Scenarios > Select "Move to [Correct Group]" > Execute.

Automatic Assignment

  • Round Robin: Equal circular distribution.
  • Load Balanced: Maximum ticket load per agent.

EMAIL MESSAGE BOX DETAILS

From (Group Email), To, CC, BCC, Body, Signature, Canned Responses (Templates), Attachments, and Send/Forward buttons.
