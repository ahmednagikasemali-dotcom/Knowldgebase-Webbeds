VCC Payment Issues L1 - Detailed Guide

Comprehensive Troubleshooting & Escalation Procedures

Overview

A provider may be unable to charge the Virtual Credit Card (VCC) we send for payment. This can happen for several reasons:

  • The provider cannot locate the VCC details.
  • The VCC has insufficient funds loaded to cover the charge.
  • The VCC is not yet active because the loading time is set for a future date.

In these cases, the provider contacts us to resolve the issue so that payment can be processed correctly.

Using the VCarly App

The first step to take is to make use of the VCarly app, found on Microsoft Teams.

Tip: After finding it on Teams, right-click and Pin it for easier access.

How to activate and use:

  1. Always start by writing a greeting like “hi” or “hello”.
  2. vCarly will validate the format of the booking reference.
  3. If the reference is correct, Dexter will display VCC Details request.
  4. You will receive a Secured URL and a Pass Code Link Request.
  5. Formatting:
    • DOTW: Provide digits only.
    • Maker: Provide the entire reference (e.g., including SH letters).

Note: Before acting, ensure the booking can be confirmed. If not, pass the case to L2.

Resolution Scenarios

Scenario 1: Provider cannot locate VCC details

Steps: Forward the email to the relevant VCC department and ask them to re-send the VCC to the provider.

Scenario 2: Insufficient funds loaded

Steps: Check the amount the provider is trying to charge vs. the VCC amount:

  • If charging more than loaded: Push back and mention the actual VCC sum.
  • If the provider still asks for more: Consider it a Rate Error and pass the case to L2.

Scenario 3: VCC not yet active (Future Loading)

Steps: Check the loading time using VCarly and inform the provider to charge the card on that specific date.
