Main Tab: DOTW Bookings

Sub Tab: Transfers & Tours

Description:
Step-by-step guide to create transfer or tour bookings in DOTWConnect.

DOTW Booking Guide

  • Click NEW BOOKING in the Operations section.
  • Select TRANSFER BOOKING from the dropdown list.
  • Enter the client name in COMPANY NAME.
  • Choose the correct profile from the dropdown.
  • Click FILTER CUSTOMERS to view user profiles.
  • Use MAIN USER if no preference specified.
  • Input PICKUP FROM and DROP OFF TO information.
  • Arrival Transfer: Pickup = Airport, DropOff = Hotel.
  • Departure Transfer: Pickup = Hotel, DropOff = Airport.
  • Enter flight date/time & total travellers.
  • Select Transfer Type (Scheduled, Private, Meet & Greet, Package) or ALL if no preference.
  • Price Currency can be changed only during booking.
  • Click Search to see available transfers.
  • Results show:
    • Transfer Info
    • Transfer Name & Type
    • Lowest Selling Price
    • Get Transfers button
  • If ON REQUEST → coordinate with supplier before booking.
  • Select transfer and click PROCEED TO BOOKING.
  • Enter guest names, pickup/dropoff info, special requests.
  • Use English characters only; no extra spaces or special characters.
  • Click BOOK TRANSFERS to finalize booking.
  • Click NEW BOOKING in Operations.
  • Select TOUR BOOKING from the dropdown.
  • Enter COMPANY NAME and choose profile.
  • Click FILTER CUSTOMERS.
  • Use MAIN USER if no preference specified.
  • Input DESTINATION CITY or TOUR NAME.
  • Enter DATE OF TOUR and TOTAL TRAVELLERS.
  • Select Tour Type (Scheduled, Private) or ALL if no preference.
  • Price Currency can be changed only during booking.
  • Click Search to see tour options.
  • Results show:
    • Tour Info
    • Tour Name & Type
    • Lowest Selling Price
    • Get Tours button
  • If ON REQUEST → coordinate with supplier before booking.
  • Select tour & time, click PROCEED TO BOOKING.
  • Enter guest names, pickup info, special requests.
  • Use English characters only; no extra spaces or special characters.
  • If transfer included, add hotel pickup; else “N/A”.
  • Click BOOK TOURS to finalize booking.
